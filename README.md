# Netflix Ad Shield

Android公式Netflixアプリ（`com.netflix.mediaclient`）の**広告再生中だけ自動で消音＆真っ黒な省電力カバーを表示**する、自分用Androidコンパニオンアプリです。

DRM回避・通信改変・広告スキップ等は一切行わず、Android標準API（`AccessibilityService`・`AudioManager`・`SYSTEM_ALERT_WINDOW`）のみで安全に動作します。

## 主な機能

1. **自動ミュート＆音量復元**
   - 広告検知時にメディア音量（`STREAM_MUSIC`）を自動ミュートし、本編復帰時に元の音量へ戻します。
2. **真っ黒な省電力カバー（OLED向け）**
   - 画面全体を黒で覆い、中央に `広告ミュート中` ＋経過時間＋大きな `強制解除（1タップ）` ボタンのみを表示します。
   - `FLAG_NOT_FOCUSABLE` を採用しているため、カバー表示中も裏のNetflix再生が自動一時停止しません。
3. **フェイルセーフ（本編無音閉じ込め防止）**
   - 終了デバウンス（1.8秒）によるチラつき防止
   - 最大継続タイマー（デフォルト90秒・設定変更可）による強制自動復帰
   - 1タップ強制解除（15秒クールダウン付き）
   - 他アプリ切替・ホーム移動・画面OFF時の即時復元
4. **実機UIノード診断モード（PC / ADB不要）**
   - NetflixのUIアップデート等で広告が検知されない場合、アプリ内で「診断モード」をONにするとNetflix画面右上に `ログ採取` ボタンが出ます。
   - 広告中に1タップすると、その瞬間のUIノード（`viewIdResourceName` / `text` / `contentDescription`）が保存され、アプリ画面からワンタップでコピーできます。

## インストールと初期設定（Android 13〜15）

1. [Releases](https://github.com/ikeda305pixel-alt/netflix-ad-shield/releases) から `netflix-ad-shield-v1.0.0.apk` をスマホにダウンロードしてインストールします。
2. アプリを起動し、以下の2つの権限を有効にします。
   - **他のアプリの上に重ねて表示**: 「設定を開く」→ 許可
   - **ユーザー補助**: 「設定を開く」→ `Netflix Ad Shield` をON
     - ※ Android 13以降でグレーアウトする場合は、先に端末の **「設定 → アプリ → Netflix Ad Shield → 右上メニュー（⋮）→ 制限付き設定を許可」** を実行してください。
3. アプリ内の **「カバー＆ミュートを3秒テスト表示」** ボタンで、真っ黒カバー・1タップ強制解除・音量復帰が正常に動くか確認します。

## もしNetflix広告に反応しない場合（スマホ単体キャリブレーション）

1. アプリ内の **「4. 実機UIノード診断モード」** をONにします。
2. Netflix公式アプリで広告が流れたら、右上に表示される **「ログ採取」** ボタンをタップします（1回タップするだけで保存されます）。
3. Netflix Ad Shield に戻り、**「更新」→「コピー」** でログを確認します。
4. ログ内の広告バッジらしき `id=...` または `text="..."` を、**「3. カスタム検知ルール」** に追加して保存すると即座に反応するようになります。
